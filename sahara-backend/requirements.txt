# ============================================================================
# Sahara backend — dependencies
# Install with:  pip install -r requirements.txt
#
# Pinning note: floors (>=) rather than exact pins are used deliberately —
# the API promises "Python 3.11+" and exact pins (e.g. numpy 1.26.4,
# torch 2.5.1) have no wheels for Python 3.13/3.14. Floor pins let pip
# resolve the newest version with wheels for YOUR interpreter, on 3.11–3.14.
#
# NOTE: torch/transformers are large (~2 GB installed). If you only want to
# run the API with the lightweight offline sentiment fallback, comment out
# the torch/transformers lines — the app boots fine without them
# (model_loaded will report False and the heuristic fallback is used).
# ============================================================================
